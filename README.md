# M Sahil — Minimal Cinematic Portfolio

React/Vite portfolio for photography, editing, color grading, and cinematic video work.

## Run locally

```bash
npm install
npm run dev
```

## Content and integrations

- Replace project media and copy in `src/data.js`.
- Set `VITE_CONTACT_ENDPOINT` to connect the inquiry form to a backend or form service.
- Without an endpoint, the form creates an email draft to `hello@msahil.studio`.
- Replace the placeholder WhatsApp number and social links in `src/main.jsx`.
